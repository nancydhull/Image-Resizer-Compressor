# 🖼️ Image Resizer & Compressor

A simple, easy-to-use photo editing web app to resize images, adjust pixel resolution, and remove backgrounds — right from your browser.

🔗 **Live App:** [https://image-resizer-compressor-1.ai.studio](https://image-resizer-compressor-1.ai.studio)



## ✨ Features

- **Resize Images** – Change the width and height of any photo as you need.
- **Adjust Pixel Resolution** – Set the pixel resolution of your image.
- **Compress Images** – Reduce the image size for easy sharing and uploading.
- **Remove Background** – Remove the background from a photo in one click.

## 🚀 How to Use

1. Open the app: [image-resizer-compressor-1.ai.studio](https://image-resizer-compressor-1.ai.studio)
2. Upload your photo.
3. Choose what you want to do – resize, change resolution, compress, or remove background.
4. Download your edited image.
